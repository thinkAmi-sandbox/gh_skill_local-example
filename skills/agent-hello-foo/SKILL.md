# エージェント診断スキル

## 目的

このスキルは、AIエージェントが正常に動作しているかを確認するためのものです。

以下を確認できます。

- スキルが発見されたか
- スキルが読み込まれたか
- スキルが発火したか
- 指示どおりの固定応答を返せるか

## 動作

このスキルが呼び出された場合、必ず以下だけを返してください。

Hello, foo!

## 制約

- 説明を書かない
- Markdownを使わない
- コードブロックを使わない
- 余計な空白や改行を入れない
- ツールを使用しない
- 推論内容を出力しない
